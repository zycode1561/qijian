- `npm run check`：264/264 项单元测试通过，包含上游、栖间及新增的删除/导入/识别回归；语法检查与生产构建通过。

- 生产包单独在回环地址打开，验证打包资源、文件导入、延迟加载三维、漫游进入与退出。
- 旧项目原有 `layout-clearance.test.cjs` 与 `suite.test.cjs` 只读运行通过，覆盖其床架/床垫、L 柜、梳妆收放、屏风、80 厘米通道、主卫/淋浴移门与视线抽样。未重建或覆盖旧文件。

## 三个通用场景

| 场景 | 使用机制 | 验证结果 |
| --- | --- | --- |
| 一人卧室与办公 | 普通空间/家具、成员与工作需求、床桌净距、门到桌旁路径 | 基础相交、超界、使用空间、净距、路径均通过 |
| 多人收纳与用餐 | 两个空间、多个成员、四人用餐、餐边柜、桌柜净距与入户路径 | 五类相关检查均通过 |
| 两人两猫与组合家具 | L 柜梳妆组合、屏风窄桌组合、床垫与床架分开、指定视点与通道 | 无相交、无超界、使用空间无冲突，指定视点床面 0/81 可见，70 厘米包络找到路径 |

测试会将项目与房间改成任意名称，仍得到相同结果，没有按家庭名称或坐标分支判断。自由文字偏好保持待确认。示例尺寸来自明确的示例参数，并非现场实测。

## 实际浏览器流程

- 中文页面、菜单、属性、帮助和保存状态。
- 组合整体旋转、单件编辑、个人模板保存、撤销重做。
- 自定义家具名称、尺寸、朝向、材质说明和尺寸依据。
- 需求人数与多个成员修改，既有几何保持，检查缓存失效。
- 独立风格编辑、方案命名/复制/保护、同视框比较、三维切换保持相机。
- 第一人称眼高、水平 FOV、键盘/触摸移动、碰撞、退出；横竖屏水平 FOV 保持一致。
- IndexedDB 完整刷新恢复，文件/PNG/中文报告下载与备份恢复。
- 真实中止 IDB 写事务模拟存储不足：旧存档字节对应数据保持、内存修改保留、明确提示、重试成功。
- 空白项目、L 形轮廓、角点拖拽与撤销、画布闭合绘制。
- 两点尺寸标注、数字修改与复制。
- 真实图片导入、两点校准、候选识别、改名修正、含底图文件恢复。
- 自定义视线目标区域、画布指定视点、阈值修改与规则停用。
- 原版 schema 4 文件进入二维/三维；schema 1–4 与栖间 schema 1 迁移另有单元回归。

## 本次删除与识别修复验证

- 家具、空间及结构条目提供可见删除入口，选中工具栏支持删除与解锁；误删可撤销。
- 图片导入后预览候选轮廓，可新建独立方案并生成二维空间和三维墙体、地面。
- 识别过滤外围尺寸线和贴墙家具，支持成对斜线填充墙；倾斜墙保留原轮廓。
- 固定缩图算法避免不同浏览器的采样差异影响识别；新增回归覆盖外侧尺寸线、贴墙床柜、斜线填充墙、倾斜墙及非整数缩放。
- 使用用户提供的原图完成本地浏览器导入、七个候选区域、二维及三维生成验证。识别仍是待校对初稿，开放区域可能合并，玄关和柜体附近的边界仍存在偏差。
- 私人户型、旧项目迁移材料及验证截图仅保存在已忽略的 `.code/`，不随仓库发布。仓库测试使用合成图形。
